プライバシーポリシー

YouTube投稿支援ツール（以下「本ツール」）における情報の取り扱いについて定めます。

1. 本ツールの性質

本ツールは、開発者本人が自身のYouTubeチャンネルを運営するために使用する私用のプログラムです。 一般に提供されるサービスではなく、開発者以外の利用者はいません。

2. 取得する情報

本ツールは、利用者（＝開発者本人）がGoogleアカウントで許可した範囲で、次の情報にアクセスします。

  • YouTubeチャンネルの動画情報（タイトル、説明文、タグ、サムネイル、公開状態）
  • YouTubeチャンネルの統計情報（視聴回数、総再生時間、平均視聴時間、チャンネル登録者の増減）
  • 認証のためのアクセストークンおよびリフレッシュトークン

氏名、住所、電話番号、支払い情報などの個人情報は取得しません。

3. 情報の利用目的

取得した情報は、動画の投稿・更新と、チャンネルの成績確認のためだけに使用します。 それ以外の目的には使用しません。

4. 情報の保存

取得した情報および認証トークンは、開発者本人の個人用コンピューター内にのみ保存されます。 外部のサーバーへ送信・保管することはありません。

5. 第三者への提供

取得した情報を第三者へ提供、販売、共有することは一切ありません。 広告配信や分析を目的とした外部サービスへの送信も行いません。

6. Google APIサービスの利用

本ツールは YouTube Data API および YouTube Analytics API を利用しています。 これらの利用にあたっては Google API サービスのユーザーデータに関するポリシー （Limited Use の要件を含む）を遵守します。 また、本ツールの利用には YouTube 利用規約 および Google プライバシーポリシー が適用されます。

7. アクセス権の取り消し

本ツールに付与したアクセス権は、 Googleアカウントのセキュリティ設定 からいつでも取り消せます。取り消した場合、本ツールは以後いかなる情報にもアクセスできません。 手元に保存された認証トークンも無効になります。

8. お問い合わせ

本ポリシーに関するお問い合わせは、GitHubリポジトリのIssueにてお願いします。

9. 改定

本ポリシーの内容は、必要に応じて改定することがあります。改定時は本ページを更新します。
